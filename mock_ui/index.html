Testing tips

  • Razorpay Checkout runs in test mode: choose Success or Failure to simulate the payment. Webhooks arrive a moment later, including a duplicate delivery that is ignored.
  • Add ?simulate=error to the page URL (before the #) to make data requests fail and see the error states, for example store/index.html?simulate=error.
  • The store and admin share the same simulated database, so open both from the same local server to see changes flow between them.
